# Report fonts

Epilogue (text and titles) and Overpass Mono (code and figures in tables), both under the SIL
Open Font License 1.1 (see `OFL-Epilogue.txt` and `OFL-OverpassMono.txt`).

The files are static instances cut from the variable fonts of the `google/fonts` repository
(`ofl/epilogue` and `ofl/overpassmono`) at weights 400, 700 and 800 (Epilogue) and 400 and 700
(Overpass Mono), because FPDF2 embeds one weight per file. Neither licence declares a Reserved
Font Name, and the family names are kept.
